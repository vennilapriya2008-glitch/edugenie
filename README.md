# EduGenie

EduGenie is a Google Gemini powered educational AI assistant.

It provides:

- Question and Answer
- Concept Explanation
- Quiz Generation
- Text Summarization
- Personalized Learning Recommendations

## Technology Stack

- Python
- FastAPI
- Google Gemini
- HTML
- CSS
- JavaScript
- Jinja2
- Optional Hugging Face Transformers
- Optional LaMini-Flan-T5

---

# 1. Requirements

Install:

- Python 3.10 or newer
- VS Code
- Internet connection
- Google Gemini API key

---

# 2. Open the Project

Open the `EduGenie` folder in VS Code.
